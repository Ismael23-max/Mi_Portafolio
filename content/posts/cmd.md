El Símbolo del Sistema (CMD) de Windows es una herramienta poderosa que te permite interactuar con tu sistema operativo mediante texto, sin necesidad de usar el mouse.

### Los comandos que debes conocer:
1. `cd` -> Cambiar de directorio (carpeta).
2. `dir` -> Listar todos los archivos y carpetas del directorio actual.
3. `mkdir` -> Crear una nueva carpeta.
4. `cls` -> Limpiar la pantalla para empezar de cero.

Perderle el miedo a la línea de comandos es el primer paso para automatizar tareas aburridas en tu día a día.
